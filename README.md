# orakul

Помощник для созвонов, который отвечает на вопрос «что мы решили?» цитатой из
той встречи, где это прозвучало. По-русски, на вашем компьютере, бесплатно.

**Состояние: ядро без приложения.** Работают поиск по созвонам, русский
словарь, архив и конвейер, который их связывает. Захвата звука и интерфейса
пока нет — запустить как программу нельзя. Написано сразу, чтобы вы не тратили
пять минут на выяснение.

```
свернуть созвон в текст  →  починить термины  →  положить в архив  →  искать
        ещё нет                  работает            работает        работает
```

## Запустить за пять минут

Нужен Swift 5.9+ (Xcode 15+) и Node 20+. Внешних зависимостей нет ни одной.

```bash
git clone <репозиторий> orakul && cd orakul

cd app && swift test        # ядро: поиск, словарь, архив, конвейер
cd ..  && node --test       # каталог кнопок, страница, идентичность приложения
```

Оба набора проходят целиком и занимают меньше минуты.

### Посмотреть, как работает поиск

```swift
import OrakulCore

let store = SessionStore(root: URL(fileURLWithPath: "/tmp/orakul"))
try store.save(.init(id: "s1",
                     title: "Планёрка по тарифам",
                     date: "2026-07-24",
                     digest: "Решили перейти на оплату за использование."))

if let hit = store.index().search("что решили по тарифам").first {
    print(hit.session.title, "—", hit.excerpt)
    // Планёрка по тарифам — Решили перейти на оплату за использование
}
```

## Почему это устроено именно так

**Поиск лексический, а не по смыслу.** В англоязычной версии поиск по
эмбеддингам не находил встречу *по названию*: две формулировки из трёх
возвращали пустоту, потому что косинус между предложениями награждает
похожесть темы, а вопрос про название спрашивает про имя. Вдобавок системная
модель предложений на macOS англоязычная и на русский текст отвечает
бессмысленным вектором. Поэтому здесь честный лексический поиск с русской
морфологией: падежи он понимает, синонимы — нет. Вопрос про «цены» не найдёт
встречу, где говорили «тарифы», и на это есть отдельный тест.

**Словарь чинит расшифровку после, а не подсказывает до.** Замерено на живой
русской речи: три движка разошлись на 29% терминов, и все спорные оказались
код-свитчингом — «прод», «промпт», «API», «джейлбрейк». Причём расходятся они
не в слухе, а в алфавите: Whisper пишет `Prompt`, Parakeet — «Промпт».
Кросс-алфавитный словарь поднял согласие с 71% до 89%. Подсказка в декодере эту
задачу не решает и умеет удалять речь: на английском корпусе такой глоссарий
довёл модель до WER 0.95 с 2757 пропусками.

**Всё считается на устройстве.** Кнопка, которой нужна сеть, не проходит
проверку при сборке — не по вкусу, а потому что каталог с ней не загружается.

## Что внутри

| Модуль | Что делает |
|---|---|
| `RecallIndex` | Поиск по своим созвонам: русские основы, редкие слова весят больше, совпадение в названии — вдвое |
| `RussianLexicon` | Канон написания терминов, включая кросс-алфавитный (`prod` → «прод», «апи» → `API`) |
| `SessionStore` | Архив на диске: файл на встречу, атомарная запись, битый файл не роняет остальное |
| `MeetingPipeline` | Сквозной путь от звука до архива; расшифровщик подключается снаружи |
| `SpeechEval` | Оценка распознавания: WER и расхождение движков без эталона |
| `PromptCatalog` | Кнопки быстрых действий, тексты — в JSON |

Ядро не знает ни про SwiftUI, ни про CoreML, ни про ScreenCaptureKit. Порт на
Windows стоит ровно того, что лежит снаружи `OrakulCore`: захват звука (WASAPI
вместо ScreenCaptureKit) и оболочка.

## Чего ещё нет

- захвата системного звука;
- настоящего расшифровщика — `Transcriber` пока протокол с одним методом;
- интерфейса;
- коннекторов к трекерам.

## Сколько стоит

Нисколько. Тарифов нет, платных функций нет, аккаунт не нужен. Всё, что делает
orakul, считается на вашем компьютере — нам это ничего не стоит, поэтому и с вас
брать не за что.
